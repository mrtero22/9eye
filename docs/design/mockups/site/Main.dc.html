How it connects →

Agents that check each other until the day is clean.

The agents work in a closed loop. The playlist check agent finds a problem and hands it to the agent that can fix it. Every fix is checked again, round after round, until every check passes. If a problem can't be fixed within your rules, the operator is notified — so no known mistake goes to air.

1

The playlist check agent runs your validators

Every check you set for the channel: timing, gaps, overlaps, media, rights, clash codes and your own rules.

Loop · repeats until every check passes
2

Each failure goes to the agent connected to that validator

A late start to the timing agent, an empty gap to the filler agent, a clash to the ad placement agent.

3

That agent fixes it

Inside its skills and your rules, logged with the reason.

4

The whole day is checked again

A fix must not cause a new problem. If anything is left, the loop runs again.

Every check passes

The day is ready for your approval, then playout.

Still failing? The operator is told

What is wrong, why, and what the agents tried — long before air.

Teach an agent once. It does the job from then on.

Write a skill — your channel's scheduling rules and way of working, in plain words — and give it to an agent. From then on it works that way every time, on every channel you choose. Change the skill, and every agent that uses it follows.

Skill

Evening breaks on Tessa One

Used by 3 agents

The job

Fill every break between 18:00 and 23:00 with the day's ads, promos and bumpers, so each break ends on the frame.

Rules

  • Alcohol only after 21:00.
  • Never two spots with the same clash code in one break.
  • A promo for tonight's premiere in every prime-time break.
  • Close any gap with a bumper from the evening rotation list.

Ask a person before

Moving a programme, or dropping a booked spot.
