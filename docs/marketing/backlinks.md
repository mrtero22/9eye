## Rules

- **Only real listings and real mentions.** Never buy links or "link packages", never use private
  blog networks, comment or forum spam, automated directory submissions or link swaps. Google
  penalises them, and 9eye.org already had one spam backlink from its previous owner.
- **The same details everywhere** (copy them from "Details" below), so every profile matches.
- **Accounts are created by the user.** Claude does not create accounts or type passwords. Once you
  are signed in, Claude can fill in a profile form in the browser and asks before submitting it.
- **Be honest about the stage:** early access; the AI agents are in preview. No competitor names.
